# External rights evidence templates

These files are fail-closed worksheets, not evidence. Copy the relevant template
outside the repository state, replace every placeholder from authoritative
written terms, attach content-addressed source documents, obtain independent
review, and only then register the resulting immutable JSON.

Rights such as backtesting, cache and retention remain exact
`qualifies_checks` claims on a `LICENSE_RECEIPT`. They are not separate Artifact
types because multiplying types would not prove that a provider granted the
claim. `ENTITLEMENT_PROBE` separately proves what the purchased account can
actually access.

Never place account identifiers, API keys, personal contact details, payment
records or private reviewer keys in these files.
