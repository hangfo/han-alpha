## 当前代码中的关键缺口

### P0：会直接造成错误风险或错误结论

1. **仓位按 signal reference 而非计划成交价计算。** 若开盘跳空或买一卖一价差扩大，真实每股风险可能超过预算。
2. **风险检查、风险预占和幂等键不是同一数据库事务。** 多 worker 可能同时通过检查并向券商重复提交。
3. **未成交订单没有进入 gross/sector/symbol/cash 风险。** Paper manual 也可能超配；`UNKNOWN` sector 可绕过行业上限。
4. **IBKR 日内 PnL 恒为 0、峰值 NLV 由当前值重置。** 这使日亏损和回撤闸门在真实连接中形同虚设。
5. **部分成交被错误视为完全成交。** `execDetails` 回调直接将 remaining 置 0；括号单子女单数量也没有随部分成交调整。
6. **模拟限价成交可穿越限价。** 买入使用 ask+slippage，卖出使用 bid-slippage，可能得到不合法的成交价。
7. **回测不是组合回测，且时序存在失真。** bars 只检查长度不检查时间戳；信号在收盘产生、次日开盘成交，但同一循环内权益标记会混入未来持仓。
8. **历史回放的 Skeptic 使用系统当前时间。** 旧证据会在回测时被一律判定过期，破坏可复现性。

### P1：Paper 长期运行前必须完成

- PostgreSQL 迁移、订单/成交/持仓/对账的规范化表、原子 outbox、单写者租约。
- Broker 启动对账、openOrder/orderStatus/execDetails/commissionReport/completedOrders 的完整事件归并。
- clientId、account、host/port 白名单；`paper_auto` 默认 false；危险操作二次确认与审计 actor。
- PIT 证券主表、ticker 变更、上市退市、拆并股/分红、交易日历、RTH/停牌/价格带。
- 数据可得时间（published/available/ingested/effective）与原始响应 hash；失败重试、缓存、速率和成本预算。
- readiness 与 liveness 分离；数据新鲜度、对账差异、挂单龄期、拒单率、kill switch 触发告警。

### P2：证明策略和 LLM 值得存在

- 无 LLM 基线、随机组合/null、市场与风格归因。
- Anchored walk-forward、purged/embargo CV、Deflated Sharpe、PBO、参数稳定性、容量与成本敏感性。
- 事件策略必须使用 surprise、guidance delta、revision、可得时间和成交量确认，不能只靠新闻标题关键词。
- LLM 结构化抽取准确率、反证召回率、校准、延迟、成本、注入攻击、模型升级回归。
- LLM on/off 盲测；只有增量收益/风险改善在冻结的 OOS 与 Shadow 均稳定，才允许进入候选链路。

## 最后提示词的具体问题与修复

1. **模型名错误。** 当前公开命名是 `gpt-5.6-sol`、`gpt-5.6-terra`、`gpt-5.6-luna`，没有 `GPT-5.6 Sol Pro`。
2. **超过 Goal 长度边界。** Goal 应只保存结果、约束、入口文件和验证方法；详细规格应在 repo 文档。
3. **依赖会话上下文。** 未来任务必须只依赖版本化文件和固定证据，不能要求 agent “阅读这个 ChatGPT 会话”。
4. **一次完成是错误的风险聚合。** 数据、回测、控制面、券商恢复、UI 和 LLM eval 应分阶段，且前一阶段未过门禁不得后移。
5. **“NOT_IMPLEMENTED 必须为空”会激励伪完成。** 正确规则是：允许明确 defer，但必须给出理由、风险、owner、目标 milestone 和阻塞证据。
6. **缺少停止条件。** 任何涉及真实账户、真实下单、付费大批量数据或模型调用，都必须再次获得明确授权。

## 可行性与时间尺度

- **研究级 MVP：可行。** 单人、熟悉 Python/交易基础设施时，合理预期 8–12 周获得可复现的 PIT 研究与无 LLM 基线。
- **可靠 Shadow / Paper：可行但更慢。** 再需要约 8–16 周完成控制面、券商恢复、故障注入、监控与至少 4–8 周连续观察。
- **Live Proposal：有条件可行。** 只能在 Paper 门禁、法律/账户权限、人工审批和灾难演练后开放，仍不自动提交。
- **无人值守自动实盘：不在本项目目标内。** 即使未来考虑，也应作为独立项目和独立安全审查。

上述时间是工程量级估计，不是承诺；数据许可、IBKR Paper 行为、市场日历与模型供应商变化都可能延长周期。
